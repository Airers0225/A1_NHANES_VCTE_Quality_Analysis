# Demographic description

Run from the repository root after placing the six DEMO/BMX/LUX files at the
manifest paths. The analysis verifies the six XPT hashes, reads frozen survey design
counts from `expected/A1_design.csv`, and checks historical missing counts using
`audit_counts.csv`. It can run before the main analysis.

```sh
Rscript --vanilla demographic_analysis/A1_Demographic_Analysis.R
```

The output is `demographic_output/A1_Demographic_Table.csv`. An optional command-line
argument selects a new output CSV path. Existing files are protected from overwrite.
Compare with the bundled aggregate [CSV](A1_Demographic_Table.csv). The [workbook](A1_Demographic_Table.xlsx)
formats the same estimates and is not generated by the R script. The [QC report](A1_Demographic_QC_Report.md)
records the original independent run. The study population is D overall and two BMI
strata for each release. The script reports weighted means and SEs, raw counts and
weighted proportions. It generates no p-values or participant-level outputs.
